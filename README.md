# Daymark Todo List

Frontend-only Todo List web app built with React, Vite, JavaScript, CSS, React Router, and localStorage.

## Features

- Simulated signup/login with remember me.
- Forgot password flow using a security question.
- Todo add/edit/delete/complete by date.
- Search and filter tasks.
- Current streak, longest streak, streak calendar, gems, and streak recovery.
- Statistics dashboard.
- Light/dark mode and Vietnamese/English translations.

## Run

```bash
npm install
npm run dev
```
